網頁設計入門

製作網站的過程中，我練習使用 HTML 建立網頁結構，並透過 CSS 設定顏色、間距、字體與版面。

學習紀錄

第一步：建立 HTML

了解標題、段落、清單與連結等基本標籤。

第二步：使用 CSS

練習設計導覽列、卡片、背景與響應式版面。

第三步：測試網頁

檢查每個頁面的連結，確認瀏覽器能正常顯示。

我的心得

網頁製作不只是把文字放到畫面上，也需要思考資訊如何安排，讓瀏覽者能快速找到想看的內容。
